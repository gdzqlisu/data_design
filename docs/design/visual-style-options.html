C · 极简克制

浅灰底 + 大量留白 + 黑色主按钮。类似 Linear / Stripe 的现代 SaaS 气质，干净专业、界面密度低；但视觉存在感弱，不容易「显得像一套风控系统」。

D · 墨色 + 琥珀

暖黑底 + 米白卡片 + 琥珀点缀，标题用衬线。有质感和辨识度，不像又一套蓝色风控系统；风险是客户可能觉得「不够传统严肃」。

选择时请一并考虑

这套风格不会只用在登录页。决策引擎控制台里最重的是决策流编排画布、规则/评分卡配置表、命中监控大盘—— 都是高密度信息页面。A 和 B 在这类页面更稳，C 最干净但需要更强的排版功力，D 最特别但要在图表配色上多做一层适配。
